# Phân tích và Xây dựng Cấu Trúc Website Template

Bài tập HTML & CSS gồm:
- `index.html`: cấu trúc website.
- `style.css`: định dạng giao diện.
- `phan-tich.md`: phần mô tả phân tích Header, Navigation Menu, Content Section và Footer.

## Chạy bài
Mở `index.html` bằng trình duyệt hoặc Live Server.

## Lưu ý khi nộp
Bài yêu cầu đính kèm ảnh chụp màn hình của một trang web thực tế đã phân tích. Hãy tự chụp trang web bạn chọn và thêm ảnh vào repository trước khi nộp.
